# NewsHub

NewsHub is a Django-based news application that allows users to register and access features based on their role. The application supports readers, editors, journalists, and publishers.

The project uses Django, Django REST Framework, and MariaDB/MySQL.

## Requirements

Before running NewsHub, install:

- Python 3.14 or a compatible Python version
- MariaDB/MySQL
- Git
- Docker Desktop (optional, for Docker deployment)

The Python dependencies are listed in `requirements.txt`.
